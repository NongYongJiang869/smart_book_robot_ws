## 引脚分配

### TB6612 电机驱动
AIN1 -> PB3  (左电机方向1)
AIN2 -> PA4  (左电机方向2)
STBY -> PA12 (待机/使能)
BIN1 -> PA5  (右电机方向1)
BIN2 -> PA6  (右电机方向2)
PWMA -> PA0  (左电机PWM, TIM2_CH1)
PWMB -> PA1  (右电机PWM, TIM2_CH2)

其中TB6612的A接的是小车的左路电机（两个，一前一后），B接的是小车的右路电机（也是两个，一前一后）

### 编码器 (速度检测)
#### 左路编码器
C1 -> PA8  (TIM1_CH1)
C2 -> PA9  (TIM1_CH2)

#### 右路编码器
C1 -> PB6  (TIM4_CH1)
C2 -> PB7  (TIM4_CH2)

### 串口 (与 RDK X5 通信)
USART2_TX -> PA2
USART2_RX -> PA3
波特率: 115200 8N1
RDK X5 侧设备: **/dev/ttyS1** (已确认)

> **注意**: 选用 USART2 而非 USART1，因为 PA9(USART1_TX) 被左编码器 C2 占用，
> PB6/PB7(USART1_REMAP) 被右编码器占用，USART2 的 PA2/PA3 空闲无冲突。

## 定时器分配

| 定时器 | 用途 | 详情 |
|--------|------|------|
| TIM1 | 左路编码器 (正交编码器模式) | PA8=CH1, PA9=CH2, 4倍频, 16bit |
| TIM2 | 电机 PWM | CH1=PA0(左), CH2=PA1(右), 1kHz, 0~999 |
| TIM3 | 编码器采样定时器 | 50Hz 中断, 计算瞬时转速 |
| TIM4 | 右路编码器 (正交编码器模式) | PB6=CH1, PB7=CH2, 4倍频, 16bit |
| SysTick | 延时 (bsp_delay) | 内核定时器, 不占用外设 |

## 串口输出格式

编码器转速通过 USART2 (PA2/PA3, 115200 8N1) 输出, 100ms 打印一次:

```
FWD L:+1234 R:+1250 | T:1234 1250     ← 前进: 左轮/右轮瞬时速度(pulse/s) + 累计脉冲
BWD L:-1200 R:-1210 | T:34 40         ← 后退: 负值表示反转
LFT L:-1300 R:+1280 | T:-1266 1320    ← 左转: 左轮反转, 右轮正转
RGT L:+1280 R:-1300 | T:-1266 1320    ← 右转
STP L:0 R:0 | T:-1266 1320            ← 停止: 转速归零
```

- `L`: 左轮瞬时转速 = 编码器脉冲差 × 50 (单位: pulse/s)
- `R`: 右轮瞬时转速
- `T`: 编码器累计脉冲数 (不清零, 正=前进方向, 负=后退方向)
- 转速转实际速度: `v_wheel(m/s) = speed(pulse/s) × wheel_circumference(m) / cpr`
