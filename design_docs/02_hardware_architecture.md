## 2. 设备连接详情

### 2.1 RDK X5 ↔ STM32

| 属性 | 值 |
|------|-----|
| 接口类型 | UART 串口 |
| 连接方式 | TX/RX/GND 三线 |
| 电平 | 3.3V TTL（两边均为 3.3V，直连即可） |
| 波特率 | **115200** |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无（由帧 CRC 保证） |
| 流控 | 无 |
| **STM32 侧** | **USART2** (USART1 的 PA9/PB6/PB7 被编码器占用) |
| **RDK X5 设备路径** | **`/dev/ttyS1`** ✅ 已确认 |

RDK X5 40pin 排针 ↔ STM32 接线：

| 信号 | RDK X5 40pin 引脚 | STM32 引脚 |
|------|-------------------|------------|
| TX   | UART1_TX (pin ?)  | RX (PA3)   |
| RX   | UART1_RX (pin ?)  | TX (PA2)   |
| GND  | GND               | GND        |

> **待确认**: RDK X5 40pin 排针上 `/dev/ttyS1` 对应的 TX/RX 物理引脚号。

### 2.2 RDK X5 ↔ OpenMV

| 属性 | 值 |
|------|-----|
| 接口类型 | USB 虚拟串口 (CDC) |
| 连接方式 | USB 数据线 |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 协议 | 文本行协议（JSON 或 key=value），参见通信协议文档 |

RDK X5 侧设备路径：`/dev/ttyACM0`（或 `/dev/ttyUSB1`，根据实际枚举顺序）

### 2.3 RDK X5 ↔ 2D LiDAR (YDLidar)

| 属性 | 值 |
|------|-----|
| 接口类型 | USB 转 UART（雷达自带 USB 转接板） |
| 连接方式 | USB 数据线 |
| 设备驱动 | `ydlidar_ros2_driver` |

RDK X5 侧设备路径：`/dev/ttyUSB0`

### 2.4 RDK X5 ↔ 机械臂

| 属性 | 值 |
|------|-----|
| 接口类型 | UART 串口 |
| 连接方式 | TX/RX/GND（5V TTL，需确认电平匹配或加电平转换） |
| 波特率 | **115200** |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验 | 无 |
| 协议 | 文本分隔符协议（`$KMS:` / `#xxxPxxx` / `$DST!` 等） |
| 臂控制器 | Arduino + 6路舵机（source.c 固件） |
| 臂运动学参数 | L0=100 L1=105 L2=75 L3=180 (mm) |
| 舵机 | 6路标准舵机，PWM 500~2500，引脚 {7,3,5,6,9,8} |

### 2.5 STM32 ↔ 电机驱动 & 编码器

底盘为**差速驱动**（左/右两侧各一组电机，同侧并联），电机为**直流减速电机（有刷）**。驱动模块为 **TB6612**（双路 H 桥），每路驱动一侧电机。

**差速驱动接线简化**（同侧两电机并联到同一路 H 桥）：

| 信号 | STM32 引脚（示例） | 目标 |
|------|-------------------|------|
| LEFT_IN1/IN2   | PB0/PB1 | 左侧电机方向（H桥 IN1/IN2）|
| LEFT_PWM        | PA0 (TIM2_CH1) | 左侧电机调速（H桥 ENA）|
| RIGHT_IN1/IN2  | PB3/PB4 | 右侧电机方向（H桥 IN3/IN4）|
| RIGHT_PWM       | PA1 (TIM2_CH2) | 右侧电机调速（H桥 ENB）|
| LEFT_ENC_A/B   | PA6/PA7 (TIM3) | 左侧电机编码器（取一侧轮即可）|
| RIGHT_ENC_A/B  | PB6/PB7 (TIM4) | 右侧电机编码器 |
| IMU_SDA/SCL    | PB10/PB11 (I2C2) | MPU6050/ICM20948 |
| EMERGENCY      | PC0 (EXTI) | 急停按钮 |
| COLLISION_F    | PC1 | 前碰撞传感器 |
| COLLISION_B    | PC2 | 后碰撞传感器 |

> **注意**：有刷电机H桥同侧并联驱动时，两个电机物理上同速旋转，但电气上共享一个PWM信号，编码器选其中一轮采集即可。若需要更精确的单轮打滑检测，可保留4路编码器。

## 3. 供电方案

```
锂电池 24V / 20Ah
  │
  ├──→ 24V 直出 ──→ 电机驱动板（电机供电）
  │
  ├──→ 24V→19V 稳压 ──→ RDK X5（专用供电口）
  │
  ├──→ 24V→12V 稳压 ──→ 机械臂电源
  │
  └──→ 24V→5V 稳压 ──→ 5V 总线
                        │
                        ├──→ STM32 板载 5V→3.3V LDO → STM32 MCU
                        ├──→ OpenMV（USB 供电）
                        ├──→ LiDAR（USB 供电）
                        └──→ 急停/碰撞传感器上拉
```

### 功耗估算

| 设备 | 功耗 | 备注 |
|------|------|------|
| RDK X5 | ~15W | 峰值 20W |
| STM32 | ~0.5W | |
| 4× 电机 | ~40W | 每个 10W，峰值 15W |
| 2D LiDAR | ~2W | |
| OpenMV | ~1W | |
| 6轴机械臂 | ~30W | 取决于负载和动作频率 |
| **合计** | **~88.5W** | 峰值约 110W |

24V 20Ah = 480Wh，理论续航约 5.4 小时（峰值），满足 ≥4 小时需求。

## 5. 底盘运动学

### 5.1 差速驱动模型（4轮 skid-steering）

假设 4 轮为同侧同速的差速驱动：

```
v = (v_left_avg + v_right_avg) / 2      -- 线速度
ω = (v_right_avg - v_left_avg) / L      -- 角速度
```

其中 `L` 为左右轮间距（轴距），`v_left_avg` 和 `v_right_avg` 是左右侧平均轮速。

编码器 → 轮速转换：
```
v_wheel = (encoder_delta / counts_per_rev) * wheel_circumference * sample_rate
```

## 6. OpenMV 安装位置

```
        机器人前视图
       ┌─────────────┐
       │             │
       │   机械臂    │  ← 臂在机器人中部
       │             │
  ┌────┼─────────────┼────┐
  │    │   OpenMV    │    │  ← OpenMV 安装在臂底座附近，朝前上方
  │    │   (相机)    │    │     视野覆盖书架1~4层高度
  └────┴─────────────┴────┘
```

OpenMV 安装角度：上仰约 15°~30°，确保能看清书架中层书籍的标签。
建议加装补光灯（LED 灯条），保证低光照环境下的识别率。
