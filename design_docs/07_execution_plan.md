
## 5. 风险清单

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| STM32 串口通信不稳定 | 中 | 高 | 帧协议加 CRC+超时检测，必要时加硬件流控 |
| QR 码在低光/倾斜角下识别率低 | 中 | 中 | 加装补光LED，控制相机仰角≤30°，增大QR码尺寸至25mm |
| QR 码距离估算精度不足 | 中 | 中 | 充分标定焦距，多次采样均值滤波，近距离(<40cm)时实际测量 |
| 机械臂适配层开发需臂协议手册 | 低 | 高 | 已确认臂有固定串口协议，获取手册后即可开发适配层 |
| LiDAR 玻璃/镜面检测失效 | 低 | 中 | 图书馆书架非镜面，风险可控 |
| Nav2 参数调不出满意效果 | 中 | 中 | 参考差速驱动机器人成熟参数模板，逐步调整 |
| 机械臂取书时书本掉落 | 高 | 中 | 优化夹爪力度，加防滑垫，多次抓取重试 |
| RDK X5 算力不足（同时跑SLAM+Nav2+视觉） | 低 | 高 | SLAM Toolbox 资源开销小，Nav2 可降频 |
| 有刷电机长期运行碳刷磨损 | 低 | 低 | 定期维护更换，设计时保留电机可拆卸结构 |

## 6. 依赖和前置条件

### 需要确认的事项

1. ✅ **底盘驱动类型** — 已确认：**差速驱动**
2. ✅ **电机类型** — 已确认：**有刷直流电机**
3. ✅ **机械臂通信** — 已确认：**串口通信，有固定控制协议**（需获取协议手册）
4. ✅ **OpenMV 型号** — 已确认：**OpenMV Cam H7 Plus**
5. ✅ **书籍标签方案** — 已确认：**QR 码**（编码内容 `book_<ID>`）
6. **STM32 型号确认** — 影响引脚分配和 HAL 库选择
7. **图书馆书架尺寸和间距** — 影响导航和取书参数
8. **臂协议手册** — 适配层开发的前置条件

## 7. 操作手册（简要）

### 建图模式

```bash
# 1. 启动建图
ros2 launch robot_bringup mapping.launch.py

# 2. 用键盘遥控推车走遍整个图书馆
# 3. 保存地图
ros2 run nav2_map_server map_saver_cli -f ~/library_map

# 4. 将 yaml+pgm 复制到 robot_bringup/maps/
```

### 导航+取书模式

```bash
# 1. 启动全系统
ros2 launch robot_bringup book_search.launch.py

# 2. 发送取书指令
ros2 action send_goal /pick_book custom_interfaces/action/PickBook \
  "{book_id: 1, book_name: '三体'}"

# 3. 查看状态
ros2 topic echo /robot_status
```

### 单模块调试

```bash
# 只启动底盘
ros2 launch robot_bringup launch/include/chassis.launch.py

# 只启动 LiDAR
ros2 launch robot_bringup launch/include/lidar.launch.py

# 键盘手动测试
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```
